# 🛒 বাজার দর (BazarDor)

### বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের বাজারদর এক নজরে

## 📌 Project Description

**বাজার দর (BazarDor)** is a modern, responsive web application designed to help users explore the latest prices of essential daily products in Bangladesh. Users can compare product prices across different markets, track price increases and decreases, browse products by category, and view detailed market price information.

The application features secure user authentication, social login, protected product details, and profile management to provide a convenient and user-friendly experience across desktop, tablet, and mobile devices.

## 🚀 Technologies Used

- **Next.js** — React framework for building the application
- **React** — Component-based user interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Responsive styling and modern UI design
- **daisyUI** — Reusable UI components
- **Better Auth** — Authentication and user session management
- **MongoDB** — Database for user and authentication data
- **Google OAuth** — Google social authentication
- **GitHub OAuth** — GitHub social authentication
- **React Hot Toast** — Success, error, and status notifications
- **REST API & JSON** — Product and category data management
- **Vercel**— Deployment platforms

## ✨ Key Features

1. **📊 Real-Time-Style Market Price Tracking**  
   Browse product prices, price changes, and market information through an animated price ticker and organized product sections.

2. **📈 Price Increase and Decrease Sections**  
   Quickly discover the top six products with rising prices and the top six products with falling prices.

3. **🛍️ Product Categories and Sorting**  
   Browse products by category and sort them by default order, lowest price, or highest price.

4. **🔎 Detailed Product Information**  
   View product descriptions, minimum price, maximum price, average price, unit information, and prices from different markets.

5. **🔐 Secure User Authentication**  
   Register and log in using email and password, Google, or GitHub authentication.

6. **🛡️ Protected Product Details**  
   Require authentication to access detailed product pages and redirect unauthorized users to the login page.

7. **👤 User Profile Management**  
   View profile information and update the user's name.

8. **📱 Fully Responsive Design**  
   Enjoy a consistent browsing experience on mobile phones, tablets, and desktop computers.

09. **🇧🇩 Bengali-Friendly Interface**  
    Present product names, market prices, units, and price changes in a familiar Bengali-language interface.
